# ثبت اطلاعات نفرات و خطاها

یک سایت ساده برای ثبت و مدیریت اطلاعات نفرات و نوع خطا.

## فیلدها

- نام و نام خانوادگی (انتخاب از لیست نفرات، همراه با کد)
- ایستگاه کاری (انتخاب از لیست ایستگاه‌ها)
- نوع خطا

## ویژگی‌ها

- افزودن، ویرایش و حذف رکورد
- جستجوی زنده
- ذخیره‌سازی در مرورگر (localStorage)
- طراحی راست‌چین و ریسپانسیو
- کاملاً فارسی

## نحوه استفاده

1. ریپازیتوری را Clone کنید یا فایل‌ها را دانلود کنید.
2. فایل‌های `index.html`، `script.js` و `style.css` باید کنار هم باشند.
3. فایل `index.html` را در مرورگر باز کنید، یا از GitHub Pages استفاده کنید.

## فعال‌سازی GitHub Pages

1. به Settings ریپازیتوری بروید.
2. از منوی سمت چپ Pages را انتخاب کنید.
3. در بخش Source گزینه **Deploy from a branch** را انتخاب کنید.
4. Branch را روی `main` و پوشه را `/ (root)` بگذارید و Save کنید.
5. بعد از چند دقیقه سایت در آدرس زیر در دسترس خواهد بود:

`https://mehdisoltani21-dot.github.io/people-manager/`
