# ثبت اطلاعات نفرات و خطاها

سایت ثبت و مدیریت اطلاعات پرسنل و خطاها.

**آدرس سایت:** https://mehdisoltani21-dot.github.io/people-manager/

## فیلدها
- نام و نام خانوادگی (انتخاب از لیست)
- ایستگاه کاری
- نوع اخطار (شفاهی / کتبی / ارجاع به کمیته انضباطی)
- نوع خطا
- تاریخ گزارش (خودکار شمسی)
- تاریخ وقوع
- توضیحات

## ویژگی‌ها
- افزودن، ویرایش و حذف
- جستجوی زنده
- ذخیره‌سازی در مرورگر
- طراحی راست‌چین و فارسی

## فعال‌سازی GitHub Pages
1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: main  |  Folder: / (root)
